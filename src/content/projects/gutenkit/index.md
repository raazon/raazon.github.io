GutenKit is a Gutenberg blocks plugin that brings the familiar ease of drag-and-drop design to the WordPress block editor, without the need for a separate page builder or any coding expertise.

## Highlights

- 🧱 A full suite of blocks for the native WordPress editor
- 🎨 Drag-and-drop layout building directly inside Gutenberg
- 📄 Pre-designed templates for faster page assembly
- 🏗️ Full Site Editing support for theme-level layouts
- ⚡ Built to stay lean compared with heavy page builder plugins

## Role

Launched GutenKit in March 2024 and grew it to 80K+ active installations while at Roxnor, establishing it as a valued addition to the company's plugin portfolio.
