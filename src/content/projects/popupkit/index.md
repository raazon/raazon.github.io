PopupKit is the popup builder plugin by Wpmet, built for the WordPress block editor. The right audience, the perfect timing, the ideal engagement.

## Highlights

- 🎯 Build popups that boost conversions, make sales, and generate leads
- 📣 Display offers, deliver target messages, and show videos
- 📊 Capture attention, create surveys, and collect feedback
- 🧱 Native Gutenberg blocks — no third-party page builder required
- ⚡ Lightweight and loaded only when it is needed

## Role

Launched and grew PopupKit to 70K+ active installations while at Roxnor, from initial release through ongoing feature development and maintenance.
